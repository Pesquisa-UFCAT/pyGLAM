pyGLAM documentation
====================

pyGLAM models continuous probability distributions with the Generalized Lambda
Distribution (GLD) family. Its FKML parameterization uses four parameters to
control location, scale and shape through a quantile function.

Start with :doc:`quickstart` to fit a model and draw samples. The
:doc:`pyglam` reference introduces the family and documents every public model
method with examples. The :doc:`performance` guide explains how to compare
reference observations with samples from a fitted model.
